# 🧰 Skills — 从真实痛点中诞生的 Claude Code 技能

> 每一个 Skill 背后，都有一段「如果AI能帮我就好了」的时刻。

这个仓库收录了我亲手打造的两个 Claude Code 技能。它们不是玩具，不是 Demo——它们诞生于真实的困境：**跨专业读研看不懂论文**，以及**面对喜欢的人不知道该怎么聊天**。

---

## 📦 收录技能

### 🎓 paper-batch-analyzer — 论文批量分析器

> "77 篇团队论文，全是矿井瓦斯抽采方向，我一个 CS 本科生，术语看不懂、方向分不清、连该先学什么软件都不知道。"

这是我的真实遭遇。本科计算机，研究生跨到资源与环境（矿井安全方向）。导师师兄一股脑发来 77 篇团队核心论文——每篇几十页，全是没听过的专业词汇：**瓦斯抽采、封孔材料、CFD数值模拟、钻杆刻槽……**

我让 AI 帮我把 77 篇论文读完了。5 份报告：

| 输出文件 | 内容 |
|----------|------|
| 📄 论文速览表 (.md + .csv) | 每篇论文的研究方向、作者、使用的软件 |
| 🔑 术语词典 | 高频专业术语 + **计算机类比解释**（比如"封孔 ≈ 端口封堵"） |
| 🛠️ 软件工具清单 | Fluent/COMSOL/MATLAB 等工具的学习路线 |
| 🗺️ 研究方向图谱 | 团队研究分布、核心作者网络 |
| 💡 论文方向建议 | 基于 CS 背景的跨学科选题（如"机器学习预测瓦斯参数"） |

#### ✨ 不只适用于矿业

修改 `references/default_keywords.json` 中的关键词分类，即可适配**任何学科**——材料、化工、地质、医学……只要你有读不完的论文，这个 Skill 就能用。

### 💬 eq-chat-advisor — 高情商聊天军师

> "抖音上有个女孩，从零开始追一个打篮球的男孩。她把所有聊天记录发了出来——从刚认识到最后暧昧，一共 300 多轮对话。"

我看完了全部聊天记录，意识到这简直是**高情商沟通的教科书**：

- 女孩「主动但不卑微」：主动出击却永远给自己留台阶，被拒绝后用自嘲化解尴尬
- 男孩「克制但温柔」：回应不多，但每条都真诚具体，从不敷衍

我把 300 轮对话做成了语料库，让 AI 提炼出两人各自的**表达 DNA**——5 个核心沟通公式、6 大关系阶段的应对策略、10 条高情商沟通原则。然后打包成了这个军师 Skill。

#### 🎯 它能做什么

| 能力 | 说明 |
|------|------|
| 🔍 分析 | 解读对方消息的潜台词、情绪信号和隐藏需求 |
| ✍️ 生成回复 | 提供 2-3 个不同风格的回复方案（大胆/温暖/安全） |
| 🎓 训练模式 | 模拟场景，给你的回复打分（分寸感/幽默/情绪价值/推进力） |
| 📊 风格解码 | 分析对方的聊天风格，判断关系阶段，预测发展走向 |

#### 📐 5 个核心沟通公式

| 公式 | 适用场景 |
|------|----------|
| **TSA**（调侃 → 软化 → 锚定） | 想表达关心但不想太肉麻 |
| **抛接升级**（Throw → Catch → Elevate） | 日常调情升温 |
| **冲突化解三步** | 表达不满但不制造紧张 |
| **特例效应**（The Exception Effect） | 测试你在对方心中是否特别 |
| **场景→情感→行动** | 不说"想你"但让对方感受到想念 |
